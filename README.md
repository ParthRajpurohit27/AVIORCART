# AVIORCART — Founder: Parth Rajpurohit



## File Structure

```
/
├── index.html          — Homepage
├── collections.html    — All products + filters
├── cart.html           — Cart page
├── search.html         — Search results
├── wishlist.html       — Wishlist
├── 404.html            — Error page
├── vercel.json         — Vercel config
├── assets/
│   ├── theme.css       — Complete AVIORCART theme CSS
│   ├── products.js     — All products as JS array
│   ├── cart.js         — localStorage cart engine
│   ├── layout.js       — Shared header/footer injector
│   ├── sw.js           — PWA service worker
│   └── manifest.json   — PWA manifest
└── products/
    └── [handle].html   —  individual product pages
```
